# Практическое задание 9

## Замер времени загрузки рейтингов

Были протестированы два способа загрузки рейтингов для списка приложений (в списке было около 40 приложений). Время замерялось с помощью `measureTimeMillis`.

### Результаты:
*   **Последовательно**: 61 612 мс (около 61.6 секунды).
*   **Параллельно**: 1 512 мс (1.5 секунды).

### Вывод:
Параллельный способ с использованием `async` и `awaitAll()` работает более чем в 40 раз быстрее.

При последовательном подходе программа ждет завершения каждого запроса по очереди (40 приложений × 1.5 сек = 60 сек). При параллельном — все запросы отправляются одновременно, поэтому общее время равно времени выполнения только одного самого долгого запроса (около 1.5 сек).
